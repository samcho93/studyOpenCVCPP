# Ch15_Camera — 웹캠 뷰어 (15차시 완성 프로젝트)

실제 웹캠(또는 동영상 파일)을 열어 실시간으로 처리하는 콘솔 + highgui 프로그램입니다.
브라우저 강좌에서 시뮬레이션 카메라로 연습한 코드가 **그대로** 진짜 카메라에서 돌아갑니다.

## 실행
1. `vs/studyOpenCVCPP.sln` 을 열고 `Ch15_Camera` 를 **시작 프로젝트로 설정**(프로젝트 우클릭) → 플랫폼 **x64** → **F5**.
2. 카메라 번호나 파일을 바꾸려면: 프로젝트 속성 → 디버깅 → **명령 인수** 에 `1` (카메라 1 번) 또는 `images/test.mp4` 같은 경로.
3. 작업 폴더는 솔루션 폴더(`vs/`)입니다. 스냅샷(`snap_001.png` …)과 녹화 파일(`record_날짜_시각.avi`)도 그곳에 생깁니다.

## 키
| 키 | 동작 |
|---|---|
| `SPACE` | 스냅샷 저장 (`imwrite`, HUD 없는 처리 결과) |
| `g` | 흑백 켜기/끄기 |
| `e` | Canny 에지 켜기/끄기 (GaussianBlur 5×5 → Canny 60/150) |
| `m` | 움직임 검출(MOG2) 켜기/끄기 — 움직이는 물체에 빨간 사각형 |
| `r` | 녹화 시작/정지 (`VideoWriter`, FourCC `MJPG`, `.avi`) |
| `h` | 도움말 출력 |
| `ESC` / `q` / 창 닫기 | 종료 |

화면 왼쪽 위에 **FPS**(10프레임 평균, `TickMeter`)와 현재 모드가, 녹화 중이면 오른쪽 위에 **● REC** 가 표시됩니다.

## 코드 구조 (`main.cpp`)
| 부분 | 내용 |
|---|---|
| `struct AppState` | 키로 바꾸는 상태(gray · edges · motion · recording · snapshot · quit) |
| `handleKey(key, state)` | 키 → 상태 변화. 화면 · 카메라와 분리되어 있어 시험하기 쉽다 (브라우저 강좌 실습) |
| `detectMotion(...)` | MOG2 전경 → 그림자(127) 제거 → 열기 · 팽창 → 윤곽선 → 사각형 |
| `drawHud(...)` | FPS · 모드 · 움직임 수 · REC 표시 (`putText` · `circle`) |
| `main` | ① 열기(`CAP_DSHOW` → `CAP_MSMF` → 기본 순서로 시도) ② 버퍼 · MOG2 · VideoWriter 를 루프 밖에서 준비 ③ 읽기 → 처리 → 녹화 · 스냅샷 → HUD → `imshow` → `waitKey(1)` ④ `release` |

## 확인할 점 · 문제 해결
- **"열 수 없습니다"**: 다른 프로그램(줌 · 팀즈)이 카메라를 쓰는 중이거나, Windows 설정 → 개인 정보 및 보안 → 카메라 → **데스크톱 앱이 카메라에 액세스하도록 허용** 이 꺼져 있습니다. USB 카메라는 번호가 `1` 일 수 있습니다.
- **녹화 파일이 비어 있음(0 KB) / 재생 안 됨**: `VideoWriter` 의 프레임 크기는 **실제로 쓰는 Mat 크기**와 같아야 하고, `isColor=true` 이면 3채널이어야 합니다. 이 프로젝트는 흑백 · 에지 화면도 3채널(`COLOR_GRAY2BGR`)로 바꿔 기록합니다.
- **FPS 가 카메라 FPS 에서 더 오르지 않음**: 측정 구간에 `cap.read()` 가 들어 있어 카메라 속도(보통 30)가 상한입니다. Canny · MOG2 를 켜서 FPS 가 떨어지는지 보세요. **Release** 빌드가 Debug 보다 훨씬 빠릅니다.
- **해상도**: `cap.set(CAP_PROP_FRAME_WIDTH, 640)` 은 요청일 뿐입니다. 실제 값은 `cap.get` 으로 다시 읽습니다. OpenCV 5 에서 지원하지 않는 속성의 `get()` 은 **-1** 을 돌려줍니다.
